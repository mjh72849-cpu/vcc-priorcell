# Aligned biological priors

These artifacts were generated by `scripts/prepare_priors.py` against the
19,197-node global vocabulary. `manifest.json` records source SHA-256 values,
parameters and exact coverage; `gene_prior_coverage.csv` provides per-gene
membership and degree counts.

| Prior | VCC genes covered | VCC target genes covered | Stored representation |
|---|---:|---:|---|
| GO | 18,074 / 18,533 | 300 / 300 | gene--term memberships |
| Reactome | 10,643 / 18,533 | 183 / 300 | gene--pathway memberships |
| STRING v12 | 18,247 / 18,533 | 300 / 300 | undirected weighted edges |
| CollecTRI | 6,551 / 18,533 | 120 / 300 | signed directed edges |
| Any source | 18,407 / 18,533 | 300 / 300 | per-source missingness retained |

STRING keeps combined score >= 400 and the union of each gene's top 64
neighbours. Reactome uses direct UniProt-to-pathway memberships, avoiding the
large duplication introduced by expanding every pathway to all ancestors.
CollecTRI retains consensus activation/inhibition direction.

Load the tensors with:

```python
from vcc_prior_model import GeneVocabularyArtifacts
from vcc_prior_model.prior_data import PriorArtifacts

vocab = GeneVocabularyArtifacts("artifacts/gene_vocabulary")
artifacts = PriorArtifacts("artifacts/priors", vocab)
priors = artifacts.load("cuda")
```

Genes missing from one source retain an inactive mask in the model. Prior
fusion uses active-source normalization, conservative gates and source-level
prior dropout, so uneven source coverage is not interpreted as a biological
zero.
